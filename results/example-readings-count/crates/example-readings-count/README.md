# The complete crate

The crate Verus checked, whole: the agent's code `src/agent/` (the files of [`../../code/`](../../code/)), the statement `src/query.rs` (the same file as [`../../spec.rs`](../../spec.rs)), the plain-array storage interface it reads (`src/stores/flat_readings/`, generated by GenDB), the fixed query entry `src/gendb_entry.rs` and the other fixed and generated files, and the SQLSpec library (`src/spec/`, `src/exec/`, `src/bridge/`, `src/link/`).

To check it with the pinned Verus:

```sh
GENDB_VERUS_HOME=/path/to/toolchains scripts/verus-check.sh results/example-readings-count/crates/example-readings-count
```
